AI Running Coach v14.5.3 · build 40503

Changes
- Preferred purchase spacing remains 12 weeks / 84 days.
- This is now an active optimisation pass, not merely explanatory text.
- If consecutive planned purchases fall inside 84 days, the planner tries to move the later pair's earliest lower-race-value sessions to suitable existing pairs with lifecycle capacity.
- The delay is transactional: if the entire shift cannot be achieved safely, all partial changes are rolled back.
- Shorter spacing is accepted only as an explicit soft-target exception where lifecycle, safety, a runner override, session suitability or Race Day readiness requires it.
- Daily Plan shoe card typography/spacing tightened.
- Compare shoe scores and Why this shoe use the same chevron as the application's other foldouts.
