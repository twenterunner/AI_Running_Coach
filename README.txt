AI Running Coach v9.5.1 Stable — build 9510

Plan-derived projection and Plan Health update

- Replaces the former fixed maximum Fitness Index gain with a plan-derived projection.
- Projected Fitness now emerges from weekly-volume progression, quality stimulus, running frequency, time available and race-specific stimulus.
- Expected plan completion, current health, training opportunity, plan quality and diminishing returns determine how much of the potential gain is realised.
- Taper benefit is calculated from the generated taper duration, volume reduction, progressive reduction and retained intensity instead of a fixed 0.6% assumption.
- Adds a transparent Plan Health score in Settings, based on weekly-volume design, long-run progression, progression safety, intensity distribution, taper structure, training frequency and target reachability.
- Plan Health includes a fold-out calculation and personalised improvement recommendations.
- Redesigns the Dashboard race outlook to lead with current and expected finish times, target margin, expected improvement, projected Fitness and Plan Health.
- Corrects the programme assumption wording to use realistic expected completion rather than perfect completion.
- Existing configurable training days, stored athlete data and external GitHub icon files are preserved.

Installation

Replace all six application files in the GitHub Pages repository. Retain the existing icon files. Fully close and reopen the installed PWA after deployment so cache build 9510 activates.
