AI Running Coach v17.0.0 — clean-slate runner UX

Design basis
- Existing calculation engine/data contracts frozen.
- Presentation designed independently from the legacy GUI.
- Industry inspiration researched: Garmin Connect/Training Readiness, TrainingPeaks athlete dashboard/performance management, modern serious-runner coaching patterns.
- Runner hierarchy: decision -> prescription -> evidence -> deep calculation detail.

Engine lock
- app.js copied unchanged from v15.4.7 baseline.
- See ENGINE_LOCK_SHA256.txt.

New UX
- New desktop athlete performance workspace with persistent navigation.
- Dedicated mobile bottom navigation.
- New page headers and purpose hierarchy per module.
- Minimal light canvas with teal performance identity.
- Consistent card, typography, form, graph and foldout grammar.
- All-data/calculation-evidence foldout added to every major screen, while preserving original engine evidence disclosures.

Known limitation
- The presentation shell is additive so existing engine DOM IDs/data hooks remain intact. Calculation code is not modified.
