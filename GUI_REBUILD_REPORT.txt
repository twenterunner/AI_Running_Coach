AI Running Coach v18.0.0 — Clean-slate runner product UI

DESIGN BASIS
- Existing calculation engines and data outputs are the product contract; the previous GUI is not.
- Industry reference principles reviewed: TrainingPeaks Athlete Home/Dashboard and Garmin Connect performance dashboard.
- Primary hierarchy: decision/action first, performance evidence second, complete calculation detail on demand.
- Visual system: light performance canvas, dark-teal navigation, teal accent, restrained semantic status colours, consistent typography, spacing, controls and data surfaces.

ENGINE LOCK
- app.js was not edited by this GUI release.
- SHA-256 is recorded in ENGINE_LOCK_SHA256.txt.

NEW PRODUCT EXPERIENCE
- New desktop athlete workspace with persistent dark-teal navigation.
- Dedicated mobile bottom navigation.
- Purpose-led screen headers and pictograms for Today, Training, Log, Performance, Recovery, Equipment, Return to Run, Race, Coach, Assessments and Settings.
- Performance, Recovery, Training and Shoes receive explicit decision/evidence data strips.
- Existing complex sections restyled into one coherent component system rather than retaining module-specific visual languages.
- Every page receives an All data & calculation evidence foldout; existing engine-specific formula/evidence foldouts remain intact.
- Existing chart mounts and calculated outputs are retained; presentation only is changed.

IMPORTANT LIMITATION
This release changes presentation only. It does not create new metrics or reinterpret existing model outputs. Where the engine does not expose an intermediate value, the UI does not invent one.
