Scope
- Restored formatting only for the Injury & Rehab rehabilitation trajectory and the metric/phase tiles directly associated with and below it.

Root cause verified
- The v15.1.7 trajectory renderer emits enhanced UI classes for phase bands, projected recovery, phase-progress tiles, phase details, timing blocks, and stage-criterion rows.
- The current stylesheet had no rules for those enhanced classes, so browser defaults were controlling their layout and visual hierarchy.

Restoration
- Added an Injury-scoped presentation regression lock for all enhanced trajectory classes.
- Re-established the approved dark-teal Level-1/Level-2 visual hierarchy.
- Restored clear observed / nominal / projected line treatments and Today marker.
- Restored compact phase tiles beneath the graph with current/completed/future states.
- Restored phase-detail, timing, and criterion-row formatting.
- Restored the mobile metric-tile layout beneath the trajectory: 2 + 1 at normal phone widths, single-column only on very narrow screens.
- No global selectors were added; all restoration rules are scoped to #injury.
