AI Running Coach v19.0.0 — Athlete OS clean-slate presentation rebuild

DESIGN BASIS
- Existing app GUI was not used as the visual reference.
- Existing app.js remains the frozen calculation/data engine.
- New presentation architecture is informed by serious-athlete patterns: immediate daily action, calendar/program structure, longitudinal performance trends, recovery decision, and progressive disclosure of evidence.

NEW PRODUCT EXPERIENCE
- Desktop: persistent compact athlete navigation rail + wide analysis workspace.
- Mobile: bottom navigation + purpose-specific responsive workspaces.
- Today: dominant execution surface, supporting coach intelligence below.
- Plan: program timeline + horizontally scannable training week + adaptation evidence.
- Log: activity feed with import/manual action separated from history.
- Performance: race outlook hero plus longitudinal fitness, durability, load, execution and adaptation dashboard.
- Recovery: current decision first, then evidence modules.
- Shoes/Injury/Race: focused workspaces using the same visual grammar rather than generic identical cards.
- Existing details/summary calculation disclosures retained and visually normalized.
