AI RUNNING COACH v15.8.4 · BUILD 51840
COMPLETE REPLACEMENT PACKAGE FOR YOUR EXISTING GITHUB PAGES APP

WHAT THIS RELEASE DOES
This build adds transparent LT1 inclusion/exclusion and quantified FIT coverage.
Re-upload a saved FIT in Log to refresh old LT1 evidence without deleting the run.

Coach Intelligence v2 replaces generic Today coaching paragraphs with a
consolidated daily/post-run evidence report. It reuses the existing fitness,
readiness, workout scoring, two-pathway and planning engines (no competing
physiology model, scoring algorithm, or new saved athlete-data schema).

PUBLISHING FROM GITHUB
1. Download AI_Running_Coach_v15.8.4_FULL_UPLOAD.zip.
2. EXTRACT the ZIP on your phone or computer. All app files are flat; the
   extracted package has no source folders to navigate.
3. Upload all extracted files to the ROOT of the repository used for GitHub
   Pages (replace existing files and add any new ones, including
   training-evidence-regression-tests.js).
4. Commit the changes. Do not change the GitHub Pages URL, repository name,
   or app origin. Wait for Pages to deploy and reopen the app.
5. Verify the app says v15.8.4 / build 51840. Open Progress →
   Automatic Aerobic Breakpoint → Observation details: accepted, partially
   accepted and excluded runs all appear with explanations.
6. For an old Hills or Easy + strides run, choose Log → Import FIT / CSV,
   select the SAME original detailed recording, then choose the new
   "Refresh recording evidence only" action. No duplicate activity is added.
   A FIT with actual elevation data is best for confirming flat sections
   within Hills. An existing compact archive cannot restore deleted samples.

IMPORTANT: GitHub's standard “Upload files” does not unpack a ZIP. Do not
upload just the ZIP file into the repo expecting the website to update.
Use the extracted individual files. The ZIP is the easy-to-transfer package.

EXISTING TRAINING DATA
Version 15.8.4 keeps storage schema 10400 and the same local storage keys.
It does not reset training history, shoes, injuries, calibrations or plans.
Avoid clearing browser data, moving the website to a new origin, or uninstalling
the PWA until you are confident your backup exists. Taking a JSON backup is a
sensible precaution; a normal app-code update does not require restoring it.

LIMITATIONS
