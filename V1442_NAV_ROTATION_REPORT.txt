AI Running Coach v14.4.2 · build 40402

ROOT FIXES

1. fewer-than-two-active-pairs
The v14.4.1 planner could create a replacement pair for a week but fail to assign that pair any session. End-of-plan cleanup then correctly removed the unused future pair, leaving only one active pair and triggering the validator.

v14.4.2 adds a committed active-rotation repair before Race Day selection. A replacement is only retained if the same week can actually allocate it at least 25% of weekly shoe mileage using whole sessions and respecting lifecycle/availability/manual locks. If it cannot be committed, the phantom purchase is removed rather than returned as an active pair. Weekly balancing is rerun after the repair.

Race Day selection is again final: no ordinary weekly rebalancing is allowed after Race Day is solved.

2. Mobile bottom navigation
The previous rule was flush to bottom:0 and depended on Android reporting a useful safe-area inset. The supplied screenshots show that this is not reliable on the user's browser.

v14.4.2 uses one global mobile navigation rule on every tab:
- 18 px minimum clearance above the viewport bottom;
- 8 px left/right inset;
- 70 px navigation height;
- 58 px button height;
- explicit icon and label rows;
- overflow visible;
- additional content clearance below every .page;
- More popup positioned above the lifted nav.
