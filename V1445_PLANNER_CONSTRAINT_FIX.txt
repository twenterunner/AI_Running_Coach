AI Running Coach v14.4.5 build 40405

Corrected the planner/validator mismatch visible in v14.4.4.

Root causes fixed:
1. Weekly validation previously checked only normal Plan sessions while the weekly
   mileage target included both Plan and rehab assignments. This could classify a
   genuinely usable pair as unable to reach 25%, producing both
   fewer-than-two-active-pairs and active-pair-below-25pct.
2. The Race Day pair was selected after the final weekly rotation balancing pass.
   Once it became physically available, validation correctly treated it as active,
   but it had never been through the same >=25% balancing rule.

Changes:
- Planner and validator now use the same complete session universe (training + rehab).
- The complete session set is carried in the lifecycle result.
- After Race Day pair selection, every affected week is rebalanced once more.
- No warning suppression was added: constraint messages disappear only if the
  generated allocation actually satisfies the constraints.
